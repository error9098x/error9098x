# Asset sources

Project images are copied without modification from the following repositories:

| Local asset | Source repository | Original path |
| --- | --- | --- |
| `projects/flagarena.svg` | [error9098x/FlagArena](https://github.com/error9098x/FlagArena) | `docs/assets/logo.svg` |
| `projects/patchy.png` | [error9098x/Patchy](https://github.com/error9098x/Patchy) | `stitch_assets/screenshots/dashboard.png` |
| `projects/metrolist.png` | [error9098x/metrolist-lite](https://github.com/error9098x/metrolist-lite) | `docs/screenshots/home.png` |

FlagArena's repository supplies a logo rather than an application screenshot. Patchy's image is the dashboard design stored in its `stitch_assets` directory. Metrolist Lite is a desktop fork of [Metrolist](https://github.com/MetrolistGroup/Metrolist).

The four SVG files in `tech/` are generated by [Skill Icons](https://github.com/tandpfun/skill-icons), retrieved on 15 September 2026. The upstream license is retained in `tech/LICENSE.txt`.

The contribution animations are generated from this account's GitHub contribution graph by [Platane/snk](https://github.com/Platane/snk). The workflow in `.github/workflows/contribution-snake.yml` refreshes the SVG files daily and also supports manual runs.
